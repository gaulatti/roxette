# Roxette

> **Disposition: archive.** Roxette is an unowned 2023 iOS media-player
> prototype with no supported release or delivery path. Keep the source
> read-only while the repository archive setting and remaining Apple account
> boundary are completed in a separate owner-controlled archive check.

The prototype is a SwiftUI shell around a single hard-coded third-party Radio
Cooperativa playlist. It has no backend, application-owned content catalog,
release workflow or test target in this source. Installation state is unknown.
The September audit reported a simulator build failure in its unused 2023
Apollo/SQLite dependency graph; the toolchain and raw build log are not retained,
and that report has not been reproduced in the current documentation review.

Do not treat a reachable third-party playlist, local signing capability,
or successful package resolution as evidence that Roxette is a live
product. Do not ship, sign, distribute, or restore the app without a named
product owner, rights review, supported stream contract, reproducible build,
and a new release plan.

See [OWNERSHIP.md](OWNERSHIP.md) for the dated evidence, recovery constraints,
and exact archive gate.
